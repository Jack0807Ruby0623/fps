I developed this on macOS. Beyond fulfilling the basic requirements, I enhanced the game with additional features:  
1. I implemented synchronized chat, allowing players to communicate via a dialogue box—press 'Y' to input and 'Enter' to send.  
2. Pressing the Tab key displays the leaderboard and KDA statistics.  
3. I designed multiple weapon types, such as a cannon and a rifle, each with distinct damage values, and assigned unique sound effects to each weapon.
